# Raw data

Do not commit the source CSV files to this repository. The working snapshot is
the three files from Figshare record 27147678:

- `auditorium_scientific_data.csv`
- `hosptial_scientific_data.csv` (the source filename contains this spelling)
- `office_scientific_data.csv`

The audit code will accept a local data-root path, so the files may remain in a
private Downloads directory. The source DOI, local snapshot checksums, and
known initial concerns are recorded in
[`docs/dataset_provenance.md`](../../docs/dataset_provenance.md).
